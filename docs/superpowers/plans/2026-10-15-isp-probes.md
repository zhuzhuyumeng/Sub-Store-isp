# ISP 状态探测增量开发

已获用户确认：导入自动探测、单个/批量重新检测、连通性/认证/延迟/出口 IP。仅修改独立 backend/isp-manager 模块。

实现顺序：
1. 本地 HTTP CONNECT、HTTPS 和 SOCKS5 代理测试及超时/异常响应验证。
2. 加入有界并发队列，结果批量落盘，使用连接修订 ID 排除过时结果。
3. 导入成功回调传递全部变更 ID；受管理鉴权保护的手动检测接口。
4. 列表检测状态与进度；轮询不重建其他单元格，不清除勾选和表单。
5. 测试、浏览器检查、重启本地服务并验证现有节点。

决定：默认 ipify HTTPS 服务、5 并发、10 秒时限、8 KiB 响应上限、不跟随重定向。检测失败保留启停状态及分享范围。任务队列不持久化，重启需重试；结果持久化。认证只报告拒绝、接受连接凭据或未知，不声称已验证强制认证。
